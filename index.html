What’s Your Anime?

Pick a character and preview your match.

Select a character to reveal a recommendation
ECS V2 · IN PROGRESS

Anime recommendations built as a multi-service platform

I love anime but struggled to understand my own taste and find recommendations that genuinely matched it. This app turns a user’s favourites into a genre profile, five matches and a reason behind each one.

Behind the experience, I’m building three containerised services on ECS Fargate and focusing on traffic routing, asynchronous work, caching, security and reliable deployments.

AWS ECS FargateApplication Load BalancerAWS WAFElastiCache RedisAmazon SQSDynamoDBTerraformGitHub Actions + OIDC
Three separate ECS services keep the user interface, recommendation logic and background event processing independent.
Redis caches common results for faster responses. SQS moves click events out of the request path so the worker can process them reliably.
WAF protects the public entry point, OIDC removes stored AWS keys, and Terraform makes infrastructure changes repeatable and reviewable.

Architecture is in progress and will be refined as I test each tradeoff.
